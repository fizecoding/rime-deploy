# 输入法配置说明

> 2026-11-09 更新。本文档记录当前输入法体系的架构、按键、文件位置与已知限制。
> 恢复步骤见同目录《恢复指南.md》。

## 一、系统架构

```
键盘输入 ──→ 鼠须管 Squirrel / Rime
                      ├─ 中文双拼（小鹤/搜狗/自然码）
                      ├─ 白霜全拼
                      └─ easy_en 英文联想（F4 或 Ctrl+` 切换）
```

| 组件 | 位置 | 作用 |
|---|---|---|
| 鼠须管 Squirrel 1.1.2 | /Library/Input Methods/ | Rime 前端（macOS 输入法框架）|
| 白霜词库 rime-frost | ~/Library/Rime/（git 仓库）| 185 万词基础词库 + 全部方案 |
| 个人中文词频 | ~/Library/Rime/personal.dict.yaml | 微信语料训练，12,207 条 |
| 个人英文词库 | ~/Library/Rime/en_dicts/personal_en.dict.yaml | 914 词（RTK/IMU/GNSS 等）|
| 英文联想方案 | ~/Library/Rime/easy_en.* | 通过 Rime 方案菜单切换的英文输入模式 |
| 动态学习层 | ~/Library/Rime/rime_frost.userdb | 日常打字实时调频 |
| iCloud 备份 | iCloud云盘/RimeBackup | 每天22:00+开机时增量 |

## 二、按键映射（最终形态）

| 键 | 功能 |
|---|---|
| 直接打字 | 中文双拼（默认小鹤），英文词混排在候选里 |
| **Shift 点一下** | 鼠须管内部中英直通切换 |
| **Shift 按住+字母** | 大写字母 |
| **- / =**（有候选词） | 上一页 / 下一页；优先于英文及符号混输 |
| **空格** | 上屏首选候选；原样输入时上屏原码（abc.123␣ → abc.123）|
| **回车** | 组字内容原码上屏 |
| **Esc / Ctrl+Backspace** | 清空全部未上屏输入 |
| **Backspace** | 逐字删除 |
| **F4 或 Ctrl+`** | 切换输入方案（小鹤⇄搜狗⇄自然码⇄全拼⇄英文）|
| 字母+符号继续输入（候选态 - = 除外） | 不再变"ABC。"，保持原样等空格上屏 |

## 三、词库三层结构

```
静态底座   cn_dicts/*（白霜，git pull 更新）
个人词频   personal.dict.yaml + personal_en.dict.yaml（语料训练产物）
动态学习   rime_frost.userdb（自动，跨4个拼音方案共享）
```

聚合点：`rime_frost.dict.yaml` 的 import_tables 里有 `- personal`；
`melt_eng.dict.yaml` 的 import_tables 里有 `- en_dicts/personal_en`。

## 四、行为配置要点

| 文件 | 内容 |
|---|---|
| default.custom.yaml | 方案列表、Shift/Caps 行为、候选态 -/= 翻页、recognizer 正则（ascii_raw 排除 -=、version_num）、Ctrl+Backspace 清码 |
| 5 个 *.custom.yaml（方案级）| F18 双向切换绑定（中文方案→easy_en，easy_en→小鹤）|
| squirrel.custom.yaml | 各 App 默认中/英（终端/VSCode/Xcode 等默认英文直通）|
| custom_phrase.txt | 固定短语（iOS、T恤 等）|

## 五、已知限制（这台机器/这套环境）

1. **TISSelectInputSource API 损坏**：程序化切换输入源返回 paramErr（疑似搜狗卸载时损坏，重启无效）。方案切换使用 Rime 内部菜单（F4 或 Ctrl+`）或偏好设置。
2. **Squirrel 的 librime-lua 无法加载 lua/ 模块**：白霜自带的 Lua 功能（rq日期、农历、以词定字）静默失效；任何 lua_processor 引用会破坏按键链。**不要再往方案里加 lua 组件**。
3. **Command 组合键不进输入法**：macOS 规定，Cmd+键直达 App。清码用 Esc/Ctrl+Backspace。
4. **候选翻页与混输的处理顺序**：`recognizer` 先于 `key_binder`，因此 `ascii_raw` 必须排除 `-` 和 `=`；若重新加入，这两个键会在候选状态被原始输入规则提前接收，导致翻页失效。
5. Karabiner 已卸载，原 Caps 长按切换和 Hyper 快捷键不再可用；恢复当前输入法时无需安装 Karabiner。

## 六、日常维护

```bash

cd ~/Library/Rime && git pull
# 之后 鼠须管菜单 → 重新部署

# 手动备份
bash ~/Library/Scripts/rime-backup.sh

# 重新训练语料（微信导出后）
python3 ~/wxexport/train_personal_dict.py <语料.txt> ~/Library/Rime ~/Library/Rime/personal.dict.yaml
# 重新部署后生效
```
