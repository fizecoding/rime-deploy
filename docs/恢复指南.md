# 恢复指南

> 备份位置：iCloud 云盘 → RimeBackup/
> 本机路径：`$HOME/Library/Mobile Documents/com~apple~CloudDocs/RimeBackup/`

## 场景一：全新 Mac 完整恢复

```bash
B="$HOME/Library/Mobile Documents/com~apple~CloudDocs/RimeBackup"

# 1. 安装鼠须管（官方 1.1.2）
brew install --cask squirrel

# 2. 恢复配置
mkdir -p ~/Library/Rime
rsync -a "$B/Rime/" ~/Library/Rime/

# 3. 恢复脚本与定时备份
rsync -a "$B/Scripts/" ~/Library/Scripts/
cp "$B/com.user.rime-backup.plist" ~/Library/LaunchAgents/
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.user.rime-backup.plist

# 4. 系统设置 → 键盘 → 输入法：添加 鼠须管（简体）+ ABC
# 5. 鼠须管菜单 → 重新部署
```

## 场景二：只恢复输入法（配置错乱/误删）

```bash
B="$HOME/Library/Mobile Documents/com~apple~CloudDocs/RimeBackup"
killall Squirrel
rsync -a --exclude 'build/' "$B/Rime/" ~/Library/Rime/
# 重新部署后生效
```
（备份每天自动更新；恢复前可先 `bash ~/Library/Scripts/rime-backup.sh` 存一份当前状态）

## 场景三：词库重新训练（语料更新后）

```bash
# 1. 从微信导出新语料（方法见下"微信语料导出"）
# 2. 训练
python3 ~/wxexport/train_personal_dict.py ~/wxexport/my_messages.txt \
    ~/Library/Rime ~/Library/Rime/personal.dict.yaml
# 3. 部署生效（鼠须管菜单 → 重新部署）
```

## 场景四：候选翻页失效排查

1. 输入 `ni` 后按 `=` 应到下一页，再按 `-` 应返回上一页。
2. 检查 `default.custom.yaml` 的 `ascii_raw` 字符集合，其中不能包含 `-` 和 `=`。
3. 原因是 `recognizer` 先于 `key_binder`；若混输规则包含这两个符号，它们会在翻页绑定之前被接收。
4. 修改后通过鼠须管菜单重新部署。

## 场景五：应急回退到 2026-11-08 之前的原始配置

```bash
killall Squirrel

```

## 附：微信语料导出（简述）

1. 微信保持登录运行；微信需重签名（详见 wcdb-key-tool 项目说明）
2. 密钥提取+解密：`wcdb-key-tool`（LLDB 抓 passphrase，需在微信内退出重登一次）
   - 工具与用法见上游项目主页
   - 数据库快照→解密→提取本人消息：
     `python3 ~/wxexport/extract_my_messages.py <decrypted/message> <wxid> out.txt`
3. 训练后建议删除明文数据：
   `rm -rf ~/wxexport/decrypted ~/wxexport/db_storage ~/wxexport/all_keys.json`
